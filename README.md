# River Room · 德州练习室

无限注德州扑克练习室，2–9 人桌。现在有两种玩法：

- **单人练习**：和 AI 同桌，随时开局（可以继续上传到纯静态网站）。
- **联网联机**：创建房间，把邀请链接发给朋友，同一张牌桌上真人对战；空座位由 AI 补齐。

## 快速开始：局域网联机

需要电脑上装有 **Node.js 20 或更高版本**（[下载地址](https://nodejs.org/)），项目本身没有任何第三方依赖。

在本目录打开终端：

```bash
node server.mjs
```

终端会打印本机地址和局域网地址，例如：

```
River Room 联机服务已启动
本机:     http://127.0.0.1:8787
局域网:   http://192.168.1.23:8787
```

1. 你在电脑上打开 `http://127.0.0.1:8787`。
2. 首页选择 **联机牌桌 → 创建房间**，填昵称。
3. 进入牌桌后点顶栏 **房间**，复制邀请链接，发给同一个 Wi-Fi 下的朋友。
4. 朋友打开链接，填昵称加入；人齐后由房主点 **开始游戏**。

也可以直接让朋友打开 `http://192.168.1.23:8787`（换成终端里打印的局域网地址），再输入 8 位房间码加入。

> 如果朋友打不开，检查两台设备是否在同一 Wi-Fi，以及 macOS「系统设置 → 网络 → 防火墙」是否拦截了 Node。

## 双击启动（快捷方式）

在 macOS 上，最简单的方式是双击项目里的启动器：

- **`启动联机.app`**（推荐，可以拖到桌面或程序坞）
- 或 **`启动联机.command`**

双击后会自动：

1. 启动游戏服务
2. 向 Cloudflare 申请一个公网地址
3. 用默认浏览器打开这个地址

看到游戏页面后，创建房间、复制邀请即可。**这个终端窗口需要一直开着**，关闭窗口、电脑休眠或断网都会让地址失效。

首次运行可能遇到：

- macOS 提示“无法验证开发者”：右键 `启动联机.app` → **打开**，或到“系统设置 → 隐私与安全性”里允许
- 提示“想要控制 Terminal”：点允许
- 没有 `cloudflared`：脚本会自动用 `npx` 下载；也可以先 `brew install cloudflared`

说明：

- 每次双击都会得到一个新的临时公网地址（Cloudflare Quick Tunnel 的特性）。
- `启动联机.app` 里写死了当前项目路径。如果移动了项目文件夹，请直接用 `启动联机.command`（它会自动定位自己所在目录）。
- 非 macOS 可以用 `npm run share -- --open`，效果相同。

## 让外网朋友加入

不在同一 Wi-Fi，就需要让服务端有一个公网地址。有两种方式。

### 方式一：临时公网链接（最快，马上开一局）

不需要服务器和域名，用 Cloudflare 的免费临时隧道：

```bash
npm run share
```

脚本会优先使用本机已装好的 `cloudflared`；没有的话会自动用 `npx` 下载官方二进制（首次约 30 MB，网络不好可能较慢）。也可以手动安装：

```bash
brew install cloudflared                              # macOS
# winget install --id Cloudflare.cloudflared          # Windows
```

脚本会自动启动游戏服务，并打印类似这样的地址：

```
公网地址：https://xxxx-xxxx.trycloudflare.com
```

**请先用这个公网地址打开游戏**，不要用 `127.0.0.1`——用内网地址打开时，复制出来的邀请链接会是内网 IP，外网朋友打不开。然后用它创建房间，点顶栏「房间」→「复制邀请」发给朋友即可。

注意事项：

- 你的电脑要一直开机联网，运行 `npm run share` 的窗口不能关；关闭、休眠或断网后链接失效，重新运行会换一个新地址。
- Cloudflare 免费临时隧道官方定位是测试用途：同时进行的请求数量有限（约 200 个，打牌完全够用）、不保证可用性；部分网络环境下 `trycloudflare.com` 可能打不开。
- 如果朋友打不开这个地址，改用方式二。

### 方式二：部署到云服务器（固定地址，不依赖你的电脑）

把整个目录放到一台能运行 Node.js 的机器上长期运行：

```bash
PORT=8787 node server.mjs     # 或 npm start
```

或用 Docker：

```bash
docker build -t river-room .
docker run -d --restart unless-stopped -p 8787:8787 -v "$PWD/.data:/app/.data" river-room
```

- 在云厂商安全组/防火墙放行对应端口，朋友访问 `http://服务器IP:8787`。
- 有域名的话建议用 Caddy/Nginx 反向代理并启用 HTTPS；没有 HTTPS 也能玩，只是「复制邀请」会退化为手动复制。
- **只运行一个实例**：房间和牌局保存在进程内存里，多实例或自动扩缩容会让不同玩家落到不同进程。
- 玩家主要在国内时，国内云主机通常比海外 PaaS 稳定；Render/Railway/Fly 这类平台部署方便、有免费额度，但免费实例空闲约 15 分钟会休眠，休眠会清空内存里的房间（正在牌局中因为有持续轮询，不会触发休眠）。

## 联机规则

- 一间房 2–9 个座位，创建时选定人数和 AI 强度。开房时由 AI 补齐，房主可以腾出空座。
- 房主负责「开始游戏 / 下一手 / 重置牌桌」；房主离开后会自动把房主转给最早加入的玩家。
- 中途加入可以选空位或接替 AI。新玩家带 2,000 筹码，在下一手发牌时入座。
- 每个座位会标注「真人 / AI」。掉线 30 秒或一回合不操作时，座位由 AI 代打，但 **token 保留**：掉线回来会自动恢复座位；超时则在行动栏点「重新接管」即可，不会再频繁提示“登录状态已失效”。
- 手机切回牌桌或网络恢复时会立即拉取最新牌局。遇到连接问题，牌桌顶部会显示「同步中…」。
- **轮到你时**，从这一回合开始算，连续 **1 分钟没有任何操作**（点击/按键/触摸/移动）会自动转 AI 代打；不是你的回合不会因为不动被托管。动一下页面或点「重新接管」即可恢复。
- 房间面板提供 **「暂时离开」** 和 **「彻底退出」**：暂时离开会把座位交给 AI，但保留重连凭证，首页出现「回到房间 CODE」，刷新/关闭重开页面也会自动恢复，加入弹窗也会显示「重新接管上一局」；彻底退出才会释放座位并清除凭证。
- 借筹码、还款、复盘、手牌记录在联机模式下同样可用。
- 支持**观战**：加入房间时勾选「只观战，不占座位」，不参与行动、看不到任何底牌，可以围观整局。
- 房主在「房间 → 座位管理」可以移出真人或 AI、补入新 AI、发指定座位邀请，或交换任意两个座位。指定座位邀请可用一次，15 分钟内有效。未开局时立即换位，开局后在下一手发牌前应用座位变更。
- 支持斗地主式**表情**：15 个表情（😂哈哈哈哈 / 😫闹麻了 / 🤡小丑 / 🍬糖完了 / 😎稳了 / 😭别这样 / 😡认真点 / 🤔让我想想 / 👏打得好 / 🍀好运来 / 💣小心了 / 🐢快点啦 / 🎉赢了！/ 🤝GG / 📱扫码了），每个 10–20 筹码，0.5 秒冷却；发送后全桌看到气泡，筹码从自己座位扣除。
- 摊牌展示公共牌、公开底牌、牌型和底池归属。电脑播放翻牌动画约 10 秒，手机直接显示结果约 3 秒。点击可跳过，单人自动下一手会等展示结束。
- **AI 辅助只在单人练习中可用**：联机房间为保证公平，会隐藏首页开关、顶栏按钮、设置项和辅助面板。
- 筹码高于 3,500 时，超出 3,500 的部分会自动用于还债，真人和 AI 都适用。
- 只有筹码低于 1,000 时才能借款；每次 2,000，累计欠款上限 10,000（最多 5 次），还清欠款后可以再借。
- 牌局中借入的筹码下手到账；即使到账前输光，下一手开始时会自动补回，不会卡住。
- 创建房间时可选择**回合时限**：15 秒 / 30 秒 / 45 秒 / 1 分钟 / 2 分钟 / 5 分钟（默认 30 秒）；超时自动过牌/弃牌，联机时该座位转由 AI 代打，可随时点「重新接管」。
- 轮到你行动时会播放三音提示音，标签页标题会变成「🔔 轮到你行动」，行动后自动恢复。
- 筹码 2,000 起步、盲注 10/20，与单人模式一致。

## AI 对手与辅助

- 每张牌桌（3 人及以上）至少会安排一位**“跟注站 / 铁头”型 AI**：入池很宽、面对下注很少弃牌、极少加注，适合练习价值下注和薄价值下注。
- 标准和高手 AI 按真人对手近来的行动分别估计弃牌、跟注和加注倾向，并区分翻牌阶段和下注尺度。样本少时以通用策略为主。
- 单人模式复用 AI 计算线程，联机减少等待时间。多人底池会限制模拟次数。
- 人多时偶尔会出现两位跟注站；2 人单挑也有约一半概率遇到。
- AI 辅助会从公开的入池率、弃牌率、加注率推断对手风格。检测到跟注站时，会**下调对手弃牌概率**，并提示“少诈唬、多价值下注”，避免给出过度野的诈唬线。
- AI 辅助仍然只在单人练习中可用。

## 近 30 天排行榜

牌桌左侧的「排行」和首页的「排行榜」都能打开。手机上使用底部的「排行」。两榜各显示前 20 手已结算的牌局。

- **最大底池**按扣除未跟注退回筹码后的底池金额排序。
- **最强牌型**按实际摊牌的完整牌力排序，同牌型也会比较踢脚牌。点进榜单可看公共牌、摊牌底牌、每个底池的分配和行动记录。
- 榜单覆盖本服务的联机对局，以及当前浏览器的单人记录。联机记录默认写入 `.data/rankings`，可通过 `RIVER_DATA_DIR` 指定数据目录。单人记录保存在浏览器里。缺少历史记录的旧牌局从新版开始累计。

使用 `npm test` 验证 AI 对不同打法的反应、房主权限、跨手换位、实时入座和排行榜保存。

## 全下特效与音效

- 电脑端全下时会显示金色特效，并暂停背景音乐以播放内置全下曲。摊牌后恢复背景音乐。
- 手机端用简短的全下提示和合成音效，减少背景音乐下载。
- 想用自己的音频覆盖内置全下曲：**设置 → 全下音效 → 选择文件**。
  - 文件只保存在你本机浏览器的 IndexedDB 里，不会上传，也不会随游戏包分发。
  - 选中后刷新页面仍然有效，点“恢复默认”可以清除。
  - 本地自定义音频只在你自己的浏览器播放，朋友不会自动听到。

## 数据与限制

- 房间和牌局保存在**服务端内存**里，重启服务会清空；没有账号系统，刷新页面会自动回到原座位，但关闭浏览器标签后需要重新用房间码或邀请链接加入；无人操作 30 分钟后房间自动回收。
- 房间码就是入场凭证，拿到邀请链接的人都能加入，请只发给认识的人。
- 服务端是权威状态：每位玩家只会收到自己的底牌，其他玩家的底牌只在摊牌时公开。

## 继续当静态网站用

`index.html`、`app.js`、`style.css` 等文件仍然可以原样上传到 GitHub Pages、Vercel 静态站、对象存储等纯静态托管。此时：

- 单人练习完全正常；
- 「联机牌桌」会提示房间服务不可用，因为没有 Node 后端。

也就是说，想联机就运行 `server.mjs`，想单机就照旧上传静态文件。

## 目录说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架、首页模式选择 |
| `app.js` | 界面、交互、联机房间客户端 |
| `server.mjs` | 联机服务：静态托管 + `/api/rooms` 房间接口 + 服务端 AI |

| `style.css` | 全部样式 |

## 常见问题

**端口被占用？**

```bash
PORT=8788 node server.mjs
```

**手机能玩吗？** 能。手机和电脑连同一个 Wi-Fi，浏览器打开终端里打印的局域网地址即可。

**为什么邀请链接是 `127.0.0.1`？** 在电脑本机用 `127.0.0.1` 打开时，页面会向服务端询问局域网地址，邀请链接会自动换成内网 IP。如果电脑有多个网卡（VPN、虚拟机），可以手动把链接里的 IP 改成终端打印的那个。

**服务端 AI 会不会很吃 CPU？** 只在 AI 行动时计算一次，普通电脑完全够用；一桌 6 人、多个房间也没问题。
